# Excel-экспорт через Telegram-бота — спецификация

## Цель
Вся статистика по подработкам — в один `.xlsx`, скачивается прямо из бота.

## Кто может
Только админы (`ADMIN_IDS`). Кнопка в админ-панели: **📤 Экспорт в Excel**.

## Экраны / кнопки
```
admin_menu:
  ...
  [ 📤 Экспорт в Excel ]  -> callback "admin:export"
        |
        v
  [ ⬇️ Всё сразу      -> "export:all" ]
  [ 📅 За текущий месяц -> "export:month" ]
  [ 📦 По работе       -> "export:pick" -> список работ -> "export:job:<id>" ]
  [ ⬅️ Назад           -> "admin:menu" ]
```

## Листы в файле
1. **Работы**: ID, Название, Дата, Время, Адрес, €/час, Часов, За смену €,
   Требуется, Набрано, Свободно, Статус.
2. **Работники**: Имя, @username, Telegram ID, Работ (шт), Часов (всего),
   Заработано €, Выплачено €, **К оплате €**, Первая запись, Последняя запись.
3. **Заявки**: Заявка ID, Работа ID, Название работы, Дата работы,
   Работник, @username, Telegram ID, Дата записи, Статус.
4. **Итоги**: все работы — кол-во, все заявки, активные, набранные,
   завершённые, общая сумма к оплате, топ-5 работников.

## Статусы для подсчёта заработка
- «К оплате» считается по заявкам `ACTIVE` + `COMPLETED` (COMPLETED — прошедшие смены).
- Если работа `FILLED/CLOSED` и дата прошла → её заявки считаем `COMPLETED`
   (либо добавим автопереход по времени — см. п. «Статус COMPLETED»).

## Открытые вопросы к Лёше
1. Заработок считать по факту записи (запланировано) или только по прошедшим сменам?
2. Ставка — фиксированная €/час из работы. Сверхурочные/бонусы нужны?
3. Отменённые заявки в «к оплате» не входят — ок?
4. Нужен ли отдельный лист «Выплаты» с отметкой «оплачено» (кто, когда, сколько)?

## Реализация
- `openpyxl>=3.1` в `requirements.txt`.
- `app/services/export.py`: `build_workbook(session) -> BytesIO`, `build_job_workbook(session, job_id)`.
- `app/handlers/export.py`: `admin:export`, `export:all`, `export:month`, `export:pick`, `export:job:<id>`.
- Отправка: `FSInputFile`/`BufferedInputFile` + кодек `utf-8`; имя файла `shiftbot_YYYY-MM-DD.xlsx`.
- Фильтр по месяцу: по `jobs.start_at` в таймзоне `Europe/Vilnius`.

## Тесты
